# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers (including people
who are just learning Linux or DevOps), and keep discussions about the work.

Report unacceptable behaviour privately to the maintainers listed in
`.github/CODEOWNERS`. Reports are handled confidentially.
